Projects

InventAza

A Flutter-based mobile application developed as the final project of the Multiplatform Application Development programme (DAM) at IES Azarquiel. InventAza provides a hierarchical school inventory management system, allowing users to browse, search and identify items across buildings and classrooms. It also supports generating and sharing PDF reports containing item details, photographs and inventory contents. Built with Dart and integrated with a school-provided REST API.

Tool Store Management

A full-stack tool store management application developed as part of the Software Engineering II subject at UCLM. Built with C#, .NET 8, ASP.NET Core, Blazor and Entity Framework Core, it provides features for managing tool catalogues, purchases, rentals, repairs and special offers. The project follows a layered architecture and was developed collaboratively using Scrum methodologies.

Opel Cars

A Java EE web application with a catalogue of Opel cars, filters by type, trim levels loaded with AJAX and test-drive booking. Built with JPA (EclipseLink) and an embedded H2 database as coursework for the Data Access module of the DAM programme.
